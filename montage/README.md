# منتاج — Montage

استديو مونتاج للحلقات اللي فيها مذيع بيشرح على الشاشة (Screencast). بتصوّر بالموبايل وبتسجّل الصوت بالـ PodMic، وClaude بيطلّع الحلقة جاهزة. شغّله بـ `/montage` أو قول «منتاج».

## بيعمل إيه

1. **يختار قناة المايك لوحده**: الـ Scarlett بيسجل قناتين، والمايك على القناة 2.
2. **يزامن الصوت مع الفيديو تلقائياً**: بيقارن صوت الموبايل بصوت المايك ويلاقي الفرق بدقة 5 ملّي ثانية.
3. **ينضّف الصوت**: يشيل الهمهمة وصوت التكييف، وفيه Compressor و De-esser، وبيظبط مستوى الصوت على **-16 LUFS** (المعيار بتاع البودكاست واليوتيوب).
4. **يقص السكتات** (اختياري `--jumpcut`).
5. **يصدّر نسختين في خطوة واحدة**: `youtube.mp4` بمقاس 16:9 و `reel.mp4` بمقاس 9:16.
6. **يدمج تسجيل الشاشة من OBS** (اختياري `--screen`): في اليوتيوب الشاشة بتبقى كاملة والكاميرا في مربع تحت على اليمين، وفي الريلز الشاشة فوق والكاميرا تحت. الشاشة بتتزامن لوحدها من صوت المايك اللي OBS سجله.
7. **يعمل ترجمة عربي** `subtitles.srt` (لو موديل Whisper موجود) و4 صور مقترحة للـ Thumbnail.

## الاستخدام اليومي

1. صوّر بالموبايل وابعت الفيديو للماك بـ AirDrop (هيروح على Downloads).
2. في Audacity: File ← Export Audio ← WAV، واحفظه في `montage/inbox/`.
3. قول لـ Claude: «منتاج الحلقة الجديدة».

أو شغّله بنفسك:

```bash
python3 montage/montage.py --video ~/Downloads/IMG_1234.MOV --audio montage/inbox/mic.wav --name "ep1" --jumpcut
python3 montage/montage.py --video ~/Downloads/IMG_1234.MOV --audio montage/inbox/mic.wav --screen ~/Movies/obs.mp4 --name "ep1" --jumpcut
```

## التحرير (HyperFrames Studio)

```bash
python3 montage/pipeline/compose.py --episode <الحلقة>
cd montage/episodes/<الحلقة>/hf && npx hyperframes@0.8.199 preview
```

Studio بيفتح على **http://localhost:3002**: فيه معاينة، وتايملاين تقص وتحرّك فيه الـ clips، وتعدّل النصوص. لما تخلص شغّل `render.py`.

## نصايح للتسجيل

- **صقّف مرة واحدة في أول التسجيل**: مش لازم، بس بتخلّي المزامنة مضمونة 100%.
- ابدأ تسجيل الصوت والفيديو في نفس الوقت تقريباً، ووقّفهم مع بعض.
- في Audacity لازم Recording channels تكون **2 (Stereo)**.
- ابعت الفيديو بالـ **AirDrop** مش بالواتساب، لأن الواتساب بيضغطه لحوالي 480 بكسل.
- لو هتسجل الشاشة، افتح البرنامج اللي هتشرح عليه **قبل** ما تدوس Start Recording في OBS.
- صوّر **أفقي** لو هتنزل على يوتيوب، والريلز هتتقص من النص تلقائياً. لو صوّرت **طولي**، الريلز هتبقى بالمقاس الكامل، واليوتيوب هيتملى بخلفية مموّهة.
- الـ HDR بتاع الآيفون مدعوم، والألوان بتتظبط تلقائياً.
